# Contributing to github-final-project

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to contribute
1. Fork this repository.
2. Clone your fork to your local machine.
3. Create a new branch for your change: git checkout -b my-change
4. Make your changes and commit them with a clear commit message.
5. Push the branch to your fork and open a Pull Request against the main branch.
6. In the pull request, describe what you changed and why.

## Reporting bugs
Open an Issue and include the steps to reproduce the problem, what you expected to happen, and what actually happened.

## Code of conduct
By participating in this project, you agree to follow the Code of Conduct (CODE_OF_CONDUCT.md).
